Behavior summary

  • On start: every checked site + every custom domain is appended to the hosts file in addition to your normal blocks.
  • Whilst running, the main dashboard’s per-site checkboxes are disabled (not hidden) with a “DEEP WORK” badge to make the lock visible.
  • The Deep Work editor section itself becomes read-only (you can’t change the default list or add/remove customs mid-session).
  • End-early goes through the existing commitment paragraph — same friction as undoing the blocker.
  • Session state is persisted; if you quit and relaunch, the timer resumes and hosts re-applies.
